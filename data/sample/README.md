# data/sample 폴더 안내

여기에는 **형식 예시**만 남긴다. 실제 회사 자료는 절대 커밋하지 말 것.

## 카테고리별 권장 파일 형식

### 1. Slack 대화 (slack_manual)
- `.txt` / `.md` / `.docx`
- 채널/스레드를 본인이 직접 복사해서 저장
- 가능하면 다음 형식을 유지:
  ```
  [09:12] 김선배: 오늘 Meta 캠페인 검수 부탁
  [09:13] 나: 네, ROAS 기준 정리해서 공유 드릴게요
  ```

### 2. 가이드 문서 (guide)
- `.docx` / `.md` / `.txt`
- 회사에서 받은 업무 가이드 / 매뉴얼 / 표준 절차

### 3. 카카오톡 대화 (kakao)
- 카카오톡 PC에서 "대화 내보내기" 기능으로 `.txt` 저장
- 기본적으로
  ```
  2025년 5월 1일 오후 2:13, 김민지 : 오늘 캠페인 세팅 끝났어요
  ```
  형식이 들어옴

### 4. Excel 가이드 (excel)
- `.xlsx` / `.xlsm`
- 시트별로 표 / 가이드 텍스트가 섞여 있어도 OK
- 시트명을 의미 있게 (예: `캠페인세팅`, `소재검수`, `KPI정의`)

### 5. 기타 (misc)
- 위에 해당하지 않는 자료는 misc 카테고리로 업로드

## 주의

- 파일명에는 한글이 포함되어도 OK (UTF-8 처리)
- 회사 보안 정책상 외부로 나가면 안 되는 내용은 업로드 전 마스킹
- Excel 한 시트가 매우 크면 색인 시간이 길어진다. 시트별 분리 권장
